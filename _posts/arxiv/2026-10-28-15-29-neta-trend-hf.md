<p><strong><a href="https://arxiv.org/abs/2610.21114" target="_blank" rel="noopener">Spectral-Spatial Interpretation</a></strong></p>
<p><span class="tag tag-llm">LLM</span> <span class="tag tag-cv">CV</span> <span class="tag tag-nlp">NLP</span> <span class="tag tag-hf">▲ 757 upvotes</span> <span class="tag tag-hf">★ 50 stars</span> · 10-22 · Haotian Ma · <a href="https://github.com/AtheavenMa/Spectral-Spatial-Interpretation" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>Post-hoc image explanations usually show where a model looks using spatial heatmaps or indicate which channels matter using global channel scores. These separate views are limiting for multispectral data because channel relevance is often spatially localized and physically meaningful. We introduce Spectral-Spatial Interpretation (SSI), a full-grid attribution method over position-channel players (g,c). For each spatial position, SSI fixes the observed surrounding context, defines a conditional game over the channels at that position, and applies the Shapley value to this local game. The result is a full spectral-spatial attribution matrix rather than a single heatmap or a global channel ranking. SSI has a clear local interpretation. It satisfies Shapley fairness within each position, and aggregating its channel attributions exactly recovers the position-level contextual contrast obtained by replacing that position with the baseline. SSI also differs from context-averaged Owen-style hierarchical accounting, which uses the same position-channel grouping but averages over external spatial coalitions. On HLS Burn Scar, SSI outperforms an MC-Owen estimator across retained attribution metrics while using only about 6% of its evaluation budget. Across CUB-200, EuroSAT, and HLS Burn Scar under both per-channel mean and zero baselines, SSI achieves the best joint deletion and insertion AUC over dense, flat, and rank-1 baselines, yields the strongest spectral hit rates and channel deletion, and leads spatial localization on both annotated datasets. Code is available at https://github.com/AtheavenMa/Spectral-Spatial-Interpretation.</blockquote>
</details>

<p><strong><a href="https://arxiv.org/abs/2610.28402" target="_blank" rel="noopener">StreamEval: Evaluating Interactive Streaming Video Generation Models</a></strong></p>
<p><span class="tag tag-llm">LLM</span> <span class="tag tag-cv">CV</span> <span class="tag tag-nlp">NLP</span> <span class="tag tag-audio">AUDIO</span> <span class="tag tag-hf">▲ 756 upvotes</span> <span class="tag tag-hf">★ 467 stars</span> · 10-22 · StreamEval Team · <a href="https://github.com/StreamEval/StreamEval" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>As streaming video generation advances, enabling real-time interaction with generated video is becoming increasingly important. We introduce StreamEval, a unified benchmark for interactive streaming video generation spanning five tasks: avatar dialogue, avatar performance, world generation, instruction editing, and reference editing. StreamEval comprises 300 scripted test cases lasting 15-300s, each specifying initial assets, incrementally arriving multimodal requests, and explicit requirements for state changes and content preservation. Performance is assessed along four evaluation dimensions: task execution, state consistency, visual fidelity, and audiovisual coordination, instantiated through ten task-specific metrics on a 0-100 scale. Evaluating 37 distinct models across 300 test cases, we find that high visual quality and identity retention do not necessarily coincide with reliable request execution or sustained state consistency. In particular, request execution remains challenging: the highest task-specific scores are 36.90 for Following among seven avatar-performance models, 25.93 for Following in text-conditioned world generation, and 15.00 for Edit Success among three reported reference-editing models. These findings identify reliable request execution under timing and preservation constraints as a central challenge for advancing omni-modal real-time interactive systems. The leaderboard is available at https://streameval.ai</blockquote>

<p><span class="tag tag-new">NEW</span> <strong><a href="https://arxiv.org/abs/2610.33568" target="_blank" rel="noopener">Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents</a></strong></p>
<p><span class="tag tag-agent">AGENT</span> <span class="tag tag-llm">LLM</span> <span class="tag tag-ml">ML</span> <span class="tag tag-cv">CV</span> <span class="tag tag-hf">▲ 344 upvotes</span> <span class="tag tag-hf">★ 5 stars</span> · 10-27 · Yihao Hu · <a href="https://github.com/yihaohu0118/Trajectory2Gym" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>Successful tool-use trajectories are not necessarily useful supervision. Even successful interactions may underrepresent multi-step dependencies or contain actions that are unjustified by the information visible to the agent at decision time. We identify two coupled requirements for effective trajectory supervision: compositional coverage, so that important observation-action dependencies are represented, and decision grounding, so that each supervised action is supported by the learner-visible interaction history. We introduce Trajectory2Gym, which constructs executable interactions around under-supported compositional structures and derives supervision only from grounded decisions in their realized executions. Structural-support selection allocates the resulting experience, while parent-normalized supervised fine-tuning preserves the semantic interaction as the unit of training weight. This reframes trajectory generation as the deliberate construction of learnable interaction experience, rather than the collection of successful trajectories. Across five Qwen3 scales, Trajectory2Gym improves Tau1, Tau2, and BFCL at every tested scale, increasing the equal-weight three-benchmark mean by 16.9-29.8 percentage points. The gains are strongest in stateful and multi-turn interaction, where later decisions depend on earlier observations and feedback. Our results suggest that scaling tool-use agents depends not only on collecting more successful trajectories, but on constructing interactions whose dependencies are represented and whose decisions are learnable from the agent&#x27;s visible history.</blockquote>

<p><span class="tag tag-cv">CV</span> <span class="tag tag-hf">▲ 294 upvotes</span> <span class="tag tag-hf">★ 31 stars</span> · 10-26 · Shengqiong Wu · <a href="https://github.com/vid-gen/awesome-video-world-model" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>Video foundation models have advanced rapidly in understanding and generating visual sequences, while video world models seek to capture the underlying dynamics of the world they depict. Despite their different objectives, both concern the relationship between video observations and an evolving world. This survey adopts world modeling as a unifying lens for examining these developments. Viewing an observed video as a partial, lossy, and temporally ordered projection of a latent temporal world, we organize the literature around four complementary operations: reading infers world properties from observed video; writing synthesizes video from specified or learned world conditions; sharing integrates understanding and generation through common modeling mechanisms; and interacting predicts and updates world states under actions and evolving observations. This perspective distinguishes temporal coherence in observed or generated sequences from consistency in the underlying world state. Across tasks, representations, models, datasets, and benchmarks, we trace a shift in emphasis from clip-level recognition and perceptual fidelity toward persistent state, controllable evolution, physical and causal validity, and evaluation grounded in interaction and downstream decisions, and we distill the open challenges that follow.</blockquote>

<blockquote>LLM agents are increasingly used to solve real-world problems, and their effectiveness depends on both the underlying models and the harnesses that support their operation. To address this gap, we introduce TraceTrial-Bench, which organizes harness reliability into seven components covering context, execution, governance, lifecycle, observability, tools, and verification. We construct 95 expert-level, mechanism-oriented tasks with executable or state-based ground truth to support semantically equivalent comparisons while preserving the native behavior of each harness. TraceTrial-Bench provides an auditable and reproducible foundation for comparing agent harnesses, diagnosing their failures, and studying how harness design interacts with model behavior.</blockquote>

<p><span class="tag tag-agent">AGENT</span> <span class="tag tag-hf">▲ 76 upvotes</span> <span class="tag tag-hf">★ 78 stars</span> · 10-23 · Meng Luo · <a href="https://github.com/Physical2RSI/Awesome-Physical2RSI" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>Recursive self-improvement (RSI) describes a system that improves not only its behavior but also the process by which it improves. Recent digital agents test this idea by rewriting their own code and checking each version with executable tests. Bringing these mechanisms into the physical world requires learning from partial observations through costly trials, while accounting for changing operating conditions and potentially irreversible consequences. We position RSI within robot learning and trace pathways from improving robot capabilities to improving the processes that generate them. We examine how physical experience can strengthen these improvement mechanisms and when the resulting gains can support further self-improvement of the mechanisms themselves. Gains carry forward only when feedback addresses remaining learning needs, the receiving component can use the change, its value survives changes in tasks or hardware, and continued practice remains safe and affordable. Existing studies, concentrated in manipulation, support behavioral improvement, benefits to later learning, and procedure improvement. Some systems also change the improver&#x27;s knowledge or tools, but the physical studies reviewed here have yet to isolate gains attributable to recursion. We synthesize these findings into evaluation principles and research directions for machines that, trial by trial, safely improve the way they improve.</blockquote>

<blockquote>Interactive world generation requires models to follow successive commands while preserving relevant history and action consequences. <blockquote>Multimodal code intelligence connects the symbolic world of programs with the visual world their execution creates. <summary>Abstract（英語）</summary>
<blockquote>Large language models need effective ways to acquire and use external knowledge beyond what they retain from pretraining. Continued pretraining risks catastrophic forgetting, while retrieval at inference time can add substantial overhead. External parametric memory avoids online retrieval, but constructing its training data requires extensive offline search, and output-level interpolation provides only shallow fusion. We introduce Deep Fusion Memory (DFM), a parametric memory architecture that reduces this construction workload and incorporates learned memory into intermediate hidden states. A causal memory predictor learns to generate memory from the preceding context, using retrieved chunk embeddings from the corpus as supervision. Memory prediction and fusion are trained end to end with the backbone frozen, and inference requires no explicit retrieval. Compared with existing parametric memory approaches, which often construct token-level memory targets, DFM requires 32times fewer retrieval queries and 2048times fewer retrieved items to construct its training data.
