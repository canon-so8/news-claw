<summary>Abstract（英語）</summary>
<blockquote>Weight-space programming, introduced in recent MIT work by Takehi et al., enables a frontier LLM agent to read a network&#x27;s weights and write a repair. Our method, Tree-Ising, casts this repair as a sparse discrete optimization problem over the model&#x27;s own BF16 weights. Our approach modifies 13% to 17% fewer weights and reduces BF16 bit flips by a factor of 2.2 to 2.3. It requires only four forward-pass requests and zero LLM tokens, with the annealing recipe costing about $0.90 in GPU time. On Qwen3.5-2B, with layers and dose selected using only the base model, the same recipe increases greedy GSM8K accuracy from 21.6% to 69.4%. <p><span class="tag tag-new">NEW</span> <strong><a href="https://arxiv.org/abs/2611.12885" target="_blank" rel="noopener">World In-Context Learning for Agentic Robot Manipulation</a></strong></p>
<p><span class="tag tag-agent">AGENT</span> <span class="tag tag-ml">ML</span> <span class="tag tag-nlp">NLP</span> <span class="tag tag-hf">▲ 65 upvotes</span> <span class="tag tag-hf">★ 47 stars</span> · 11-11 · Heng Fang · <a href="https://github.com/ArcheOne-AI/RoboScript" target="_blank" rel="noopener">GitHub</a></p>
<details>
<summary>Abstract（英語）</summary>
<blockquote>Trained action policies write manipulation skill into network weights, tying what is learned to the distribution it is learned from. In-context learning (ICL) avoids this coupling but has not matched trained policies, because a demonstration recorded in another scene carries no feedback from the world the robot currently faces. We observe that what an agent learns in context is semantic, recording task steps and object roles rather than visual appearance, so experience gathered in one world transfers to another. Based on this insight, we propose World In-Context Learning (WICL), a paradigm in which a frozen model starts from a demonstration, rehearses the task in a world such as a simulator, and writes the feedback into its context rather than its weights. We build RoboScript, a modular infrastructure that implements WICL for agentic manipulation.
